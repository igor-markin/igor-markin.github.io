minion-redmi

minion-redmi is a personal automation tool used by one person, Igor Markin. It is not offered to the public and has no user accounts.

It runs on an old phone at home and processes documents, audio and public web pages into plain text. It uses rclone to save the results to a folder in Igor's own Google Drive.

Google data

The app requests one Google permission, the drive.file scope. This scope allows it to see, edit, create and delete only the Google Drive files that it created or that were opened with it. It has no access to any other files in the account.
